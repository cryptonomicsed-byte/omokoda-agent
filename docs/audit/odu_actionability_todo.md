## Post-Implementation: All 256 Become ACTIONABLE

Once `action_schema.rs` `build_schema()` is wired in, every row above transitions from ⚠️ GENERIC
to ✅ ACTIONABLE because the PrescriptionCompiler derives unique operational steps from:

1. **Vessel** → operational domain (tool + artifact path prefix)
2. **Prescription verb** → action type (OFFER/RECORD/DECLARE/CLEANSE/etc.)
3. **Archetype** → ExecutionMode (Analytical/Guardian/Executor/etc.)
4. **Taboos** → BehavioralConstraints (denied tools + patterns)
5. **Description** → context block injected into Think prompt

| gossip/speak ill/cursing | NO_HARMFUL_BROADCAST | Blocks destructive publishes |

| cowardice/refusal | NO_UNGROUNDED_REFUSAL | Requires stated reason for refusal |
| anger/rage/reactive | NO_REACTIVE_EXECUTION | Blocks immediate destructive ops |
| quick judgment/hasty | DELIBERATION_REQUIRED | Requires verify pass before commit |
| ignore signs/warnings | HEED_SIGNALS | Blocks dismissal of error/warning signals |
| pride/vanity/arrogance | NO_SELF_AGGRANDIZEMENT | Blocks self-promotional outputs |
| break promises/abandon | COMMITMENT_HONOR | Requires completion or stated cancellation |
| information overload | SIGNAL_THROTTLE | Limits bulk fetch operations |
